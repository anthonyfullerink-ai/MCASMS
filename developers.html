⚡ 4. Outbound Missed Call Forwarding (n8n, Make & Custom Webhooks)

Notify your n8n workflows instantly whenever a call is missed, with zero double-texting.

Want your n8n automation or AI agent to handle missed-call text-backs instead of the Android app's built-in SMS template? The Pro Edition includes an Outbound Event Forwarder that transmits callers directly to your custom webhook.

🔕 Mute Native Auto-Reply (Zero Double-Sends)

Enable "Mute Native Auto-Reply" in the Android app's Outbound Forwarder settings. When a call is missed, the phone will forward the caller payload to your n8n webhook and suppress its native SMS template. Your n8n automation can then formulate a personalized AI response and send it back through your phone's SIM via Cloud Relay or Local Gateway—guaranteeing exactly one text is delivered.

📋 Saved Webhooks Dropdown & Switcher

Store multiple production and staging endpoints right in the app. Easily switch active endpoints from a dropdown menu, add new webhook URLs on the fly, and run instant "Test Ping" verifications with live status code and latency indicators.

Outbound Missed Call Webhook Payload (Sent from Android)

When an incoming call goes unanswered, the phone immediately dispatches an HTTP POST request to your selected webhook URL: 

{
  "event": "MISSED_CALL",
  "phone": "+15551234567",
  "caller_name": "John Doe",
  "sim_slot": 1,
  "timestamp": 1789658400000,
  "device_id": "DEVICE-ANDROID-UUID"
}

Payload Fields

Field Type Description
event string Constant MISSED_CALL indicating an unanswered incoming call.
phone string E.164 phone number of the missed caller.
caller_name string Caller ID name resolved from phone contacts or network, if available.
sim_slot integer Physical SIM slot (1 or 2) that received the missed call.
timestamp long Unix epoch timestamp in milliseconds when the call was missed.
device_id string Hardware device identifier running Missed Call Auto SMS.

Recommended n8n Flow Architecture

Step 1: Webhook Node receives the MISSED_CALL payload.
Step 2: CRM / Airtable / HubSpot Node checks if the contact is an existing client or hot lead.
Step 3: OpenAI / Claude Node drafts a customized, context-aware reply.
Step 4: HTTP Request Node calls https://missedcallautosms.com/api/dispatch-sms with the drafted message.
Result: Your physical Android phone fires the text message over your cellular carrier plan, keeping conversations 100% natural and never double-sent!

🛡️ 5. Platform Stability, SLA & Resilience Specification

Engineered from the kernel up to run 24/7/365 without sleep drops, memory kills, or carrier flags.

🔋 24/7 Foreground Service & WAKE_LOCK

Consumer Android apps get suspended when the screen locks. Missed Call Auto SMS registers an Android Foreground Sticky Service with a persistent notification bar icon and acquires partial CPU wake locks during incoming call events. It will never be killed by Android memory managers.

🛡️ SIM Burn Safeguard™ (Carrier Anti-Spam)

Mobile carriers (Verizon, AT&T, T-Mobile) will flag consumer SIMs if hundreds of texts fire in seconds. Our engine enforces a strict 3.5-second sequential pacing interval and a 20 SMS/minute burst ceiling. Your phone line remains 100% compliant and healthy.

📦 WorkManager Persistent SQLite Queue

If the phone momentarily enters a basement or elevator with zero cell service, outbound dispatches do not vanish. They are queued to an encrypted SQLite database via Android WorkManager and automatically flushed the instant cellular towers re-acquire connection.

☁️ High-Priority FCM Push Redundancy

Central Cloud Relay leverages Google Firebase Cloud Messaging at HIGH_PRIORITY level. This bypasses Android Doze mode and wakes the device radio within milliseconds, ensuring real-time response times for critical lead generation workflows.

⚠️ Crucial Device Setup Step: Disable Vendor Battery Optimization

Certain Android manufacturers (Samsung OneUI, Xiaomi MIUI) aggressively throttle background apps unless instructed otherwise. On your appliance device, navigate to Settings ➔ Apps ➔ Missed Call Auto SMS ➔ Battery ➔ Select "Unrestricted" to ensure zero sleep interruptions.

🎙️ 7. Turnkey AI Voice Receptionist ($29/mo) & Telephony Forwarding API

Integrate Vapi, Retell, LiveKit, or native carrier SIP trunking for unanswered call triage and AI conversational voice handling with zero contractor technical setup.

🔄 Dual-Track Triage Architecture

Missed Call Auto SMS combines instant SMS auto-replies via native Android SIM with an autonomous AI voice receptionist via conditional carrier forwarding:

  1. Native Cell Ring (0–15s): Incoming calls ring the contractor's physical phone. If answered, normal phone conversation proceeds at $0 AI cost.
  2. Carrier Conditional Forwarding: If unanswered after 15s or busy, the mobile carrier automatically routes the audio stream to your dedicated Vapi AI endpoint.
  3. Dynamic Context Injection: Vapi queries POST /api/vapi/webhook. The server retrieves the contractor's profile and returns a dynamic system prompt containing their business name, technician name, service trade, and custom greeting.
  4. Conversational Guardrails: AI operates under strict voice UX rules: maximum 20 words per spoken sentence, mandatory phonetic street address read-back confirmation, and a 3-minute hard ceiling.
  5. Post-Call Dispatch: Once hung up, full audio transcript and extracted urgency metadata trigger automated lead alerts to the contractor and SMS booking confirmations to the homeowner.

📡 Carrier Conditional Call Forwarding Matrix

The Android app's CarrierForwardingManager auto-detects the active SIM carrier and triggers the native phone dialer with the appropriate MMI/USSD prefix:

Carrier / MVNO Forwarding Prefix (Activation) Deactivation Code Behavior
Verizon / Visible / US Cellular *71{10-digit-number} *73 Rings handset for 15s; forwards on no-answer or busy.
AT&T / Cricket / Consumer Cellular *004*{10-digit-number}# ##004# Conditional forwarding for unanswered, busy, or unreachable calls.
T-Mobile / Mint Mobile / Metro **61*{10-digit-number}**15# ##004# Explicit 15-second timer before forwarding to AI endpoint.
Generic US Carrier / Landline *71{10-digit-number} *73 Standard North American conditional call forwarding standard.
